# 本地词典导入规范

## Purpose

本能力允许用户将自有的多格式本地词典及配套资源导入阅读，建立可离线查询、可取消且可恢复的词典集合，并明确格式不支持、文件缺失和导入失败时的行为，避免将普通电子书或未完成的词库误认为可用词典。

## Requirements

### Requirement: 首版必须按真实结构支持七类本地词典

系统 MUST 支持 MDict、StarDict、Kindle MOBI/PRC、DSL、DICTD、XDXF、BGL 七类词典的词条导入与离线查询，并为支持的版本、编码、压缩及资源变体提供经过样本验证的清单。系统 MUST 依据文件结构识别格式，不能仅凭扩展名或词典名称认定兼容；MOBI 家族 MUST 验证词典索引，兼容文件使用 `.azw` 扩展名时仍按内容处理。

#### Scenario: 导入各类代表性词典

- **WHEN** 用户分别导入七类格式中已列入支持清单、必要文件齐全的有效样本
- **THEN** 每个样本都能完成导入并查询其预期词头、别名和适用资源
- **AND** 列表显示真实词典名称、格式和可用状态

#### Scenario: 扩展名相同但内容不适用

- **WHEN** 用户导入无词典索引的普通 MOBI 电子书、损坏文件或受 DRM 保护的词库
- **THEN** 系统给出对应失败原因，不将该文件发布为可查询词典

#### Scenario: 遇到未支持的格式变体

- **WHEN** 文件属于已识别格式但其版本、编码或必要正文类型尚不受支持
- **THEN** 系统报告具体兼容限制，不把空释义或静默丢失正文当成导入成功

### Requirement: 多文件词库必须整体识别和关联资源

系统 MUST 允许选择文件、多个配套文件和目录，按选中词典的真实文件组关联主文件、索引、别名、样式、图片及音频。已发布副本与身份校验 MUST 只包含该文件组和明确关联资源，不能因共享父目录而包含未选择的其他词库及无关文件。必要文件缺失 MUST 阻止导入并说明内容；可选资源缺失 MUST 可见提示且不丢失可读取文字。归属不明的资源 MUST 提供明确关联或补选入口，不得静默遗漏已引用必要内容。系统 MUST 只读取用户授予访问权的内容。

#### Scenario: 导入完整文件组

- **WHEN** 用户选择带配套 MDD 和样式的 MDX，或带索引、别名与资源的 StarDict 文件组
- **THEN** 系统将整组识别为对应词典并保留本地资源关联

#### Scenario: 单文件授权不足

- **WHEN** 用户只选择主文件，而必要配套文件尚未授权或不存在
- **THEN** 系统提示补选文件或目录，不能假定拥有父目录访问权

#### Scenario: 缺少可选声音或图片

- **WHEN** 必要正文和索引完整但部分可选资源不存在
- **THEN** 系统允许导入可读取内容，并在导入结果和相关释义显示资源缺失提示

#### Scenario: 同一目录仅选择一本词典

- **WHEN** 授权目录或归档在同一父目录包含多本词典，用户只选择词典甲
- **THEN** 甲的发布副本仅包含其文件组及已关联资源，不包含未选词典乙及其无关配套
- **AND** 甲的身份不受乙或其他无关兄弟文件增删影响

#### Scenario: 资源由多本词典共同使用

- **WHEN** 用户明确关联可供甲乙使用的共享资源
- **THEN** 两本词典保留各自可用资源副本，删除其中一本不破坏另一本
- **AND** 不因资源归属不明而默认复制整个父目录

### Requirement: 常用归档必须解包后再识别词典

系统 MUST 支持有效的 ZIP、普通单卷 RAR、7z 和 tar.gz 归档导入，并在解包后按词典文件组识别内容。词典自身采用的压缩形式 MUST 按格式兼容清单处理。系统 MUST 对分卷及带密码归档给出先解压再导入的说明，不能把首卷当完整词库。

#### Scenario: 压缩包包含多本词典

- **WHEN** 用户导入包含多个完整词典文件组的受支持归档
- **THEN** 系统列出可识别的词典供用户选择导入，并保持各自资源关联

#### Scenario: 归档无法完整读取

- **WHEN** 用户选择分卷、带密码或损坏的归档
- **THEN** 系统说明原因，不发布由部分内容生成的词典

### Requirement: 导入必须可取消并原子发布

系统 MUST 在后台导入并显示阶段或进度，允许用户取消。只有原文件、必要资源和查询索引均准备完成后才能显示可用；失败、取消或进程终止 MUST 不损坏已有词典。重启后 MUST 能识别未完成任务并提供重试路径。

#### Scenario: 导入成功

- **WHEN** 全部必要内容处理及校验完成
- **THEN** 词典一次性进入可用状态，能够执行查询

#### Scenario: 导入中断或空间不足

- **WHEN** 导入被取消、应用进程终止、文件损坏或可用空间不足
- **THEN** 系统不留下可查询的半成品，已有词典保持可用
- **AND** 中断任务的临时内容可清理，并能够重新导入

### Requirement: 导入必须约束文件及资源边界

系统 MUST 限制导入文件数量、解压体积及解析资源消耗，并拒绝越界路径、异常长度及无效偏移。词库内容 MUST 不能通过导入访问或覆盖词典工作目录以外的文件。

#### Scenario: 归档或资源尝试越界

- **WHEN** 归档条目、链接或资源路径指向允许目录以外的位置
- **THEN** 系统拒绝该内容并给出失败信息，目标目录外的文件保持不变

#### Scenario: 数据超过可处理限额

- **WHEN** 解压体积、条目数量或解析数据超过已定义限额
- **THEN** 系统中止导入并说明限制，不因继续分配内存而使应用失去响应

### Requirement: 词典管理必须保留原文件并区分身份

系统 MUST 提供词典信息、排序和删除操作，保存应用管理的词典副本；外部原文件移动或删除不能影响已导入词典。相同真实文件组再次导入 MUST 避免重复存储，身份校验不得包含无关兄弟文件；同名不同内容 MUST 可区分并存，不能静默覆盖。身份规则升级 MUST 保留旧词典 ID、排序、文件、可用索引及偏好引用，验证失败或取消时保持旧可用数据。删除 MUST 仅清理应用内对应文件、资源和索引，不自动清理旧副本中多带的文件或其他词典。

#### Scenario: 重复导入或同名词典

- **WHEN** 用户导入已存在的相同真实文件组，或名称相同但内容不同的词典
- **THEN** 相同文件组复用已有身份，不同内容可区分并存

#### Scenario: 来源移动及词典删除

- **WHEN** 用户移动原文件后查询已导入词典，再在应用中删除该词典
- **THEN** 移动来源不影响查询，应用删除操作不修改外部原文件

#### Scenario: 查询索引需要恢复

- **WHEN** 已导入词典的索引损坏或需要升级
- **THEN** 系统使用保留文件重建，显示状态和失败重试入口
- **AND** 其他词典、用户语言设置及旧完整副本不受失败影响

#### Scenario: 无关文件变化后重复导入

- **WHEN** 用户增删无关兄弟文件，或把同一完整文件组移到另一父目录再次导入
- **THEN** 原词典仍被识别为已有内容，ID、排序及首选或候补引用保持
- **AND** 实际正文或已关联资源内容变化仍可识别为不同内容

#### Scenario: 旧文件组身份升级中断

- **WHEN** 系统升级旧身份规则，但取消、验证失败或资源归属无法明确
- **THEN** 已有词典继续使用旧身份及可用索引，原文件不删除
- **AND** 系统不以失败重建或新 ID 静默替换旧记录

### Requirement: 词库语言必须允许用户明确指定

系统 MUST 展示词库声明的输入及输出语言，并允许用户明确指定缺失或不准确的查询语言。用户指定 MUST 优先用于语言首选和候补组织，跨重启、索引重建及备份恢复保持；原始语言信息不得被不可逆覆盖。未分类词库 MUST 保留手动查询能力，但不能自动归入某个语言候补集合。

#### Scenario: 词库缺少或错误声明语言

- **WHEN** 词库未声明语言或声明与实际不符，用户明确指定其查询语言
- **THEN** 该词库能够加入对应语言的首选或候补，原始信息仍可查看
- **AND** 重启和索引重建不撤销用户指定

#### Scenario: 未分类词库继续可用

- **WHEN** 用户尚未对缺失语言的已有词库分类
- **THEN** 词库仍保留且能够主动手动使用
- **AND** 系统不凭文件名或应用语言把它自动加入中文或英文候补
