# 本地词典备份规范

## Purpose

本能力将本地词典目录及偏好纳入阅读的备份恢复体系，同时允许用户选择是否备份体积较大的词库与资源，保证清单、实际文件和查询就绪状态一致，并在保持旧版备份兼容的前提下恢复用户的上次词典选择。

## Requirements

### Requirement: 普通备份必须保存清单与偏好

系统 MUST 在普通备份中保存带版本的词典清单、顺序、身份校验信息和语言首选、有序候补、用户词库语言指定及兼容旧选择的信息；按书即时开关及明确语言提示 MUST 跟随原有书籍设置备份。普通备份 MUST 默认不包含原文件、资源或索引，不依赖原设备绝对路径，并说明恢复后可能需重新导入。恢复偏好 MUST 引用正确身份，不静默替换为另一同名词典。

#### Scenario: 创建普通备份

- **WHEN** 用户未勾选包含词典文件而执行备份
- **THEN** 备份保存词典清单及新旧偏好，书籍设置保留按书开关，不打包正文、资源或索引

#### Scenario: 在新设备恢复普通备份

- **WHEN** 用户恢复只有清单的备份且设备没有对应词库
- **THEN** 系统恢复清单与偏好引用并标记待重新导入，不将条目标记为可查询
- **AND** 重新导入可可靠匹配的文件后能够关联原 ID 及首选、候补；不能可靠匹配时保留记录并提供明确关联入口

### Requirement: 完整备份必须包含查询所需原始资源

系统 MUST 提供显式选项将词典真实文件组及已关联资源加入完整备份，并保存相应身份版本及校验信息；未选词库和无关兄弟文件 MUST 不因同处父目录而被新完整备份打包。可重建索引 MUST 不作为必需数据。恢复成功后 MUST 映射词典 ID、排序、语言指定、首选和候补，并能离线查询。用户 MUST 知晓文件备份增加体积。

#### Scenario: 创建并恢复完整备份

- **WHEN** 用户选择包含词典文件并在另一设备恢复成功
- **THEN** 真实原文件组、必要配套及已关联资源得到恢复，索引重建后能离线查询
- **AND** 顺序、语言指定、首选及候补按恢复后身份对应关系恢复

#### Scenario: 避免重复打包同目录其他词库

- **WHEN** 词典甲来自曾含甲乙的同一父目录，创建新完整备份
- **THEN** 甲的备份只包含已确定的甲文件组及资源，不将未关联的乙文件混入甲目录
- **AND** 旧应用内副本不会因此自动删除或清理

### Requirement: 恢复必须校验内容并避免静默覆盖

系统 MUST 按备份声明的身份版本校验路径、文件组完整性和内容；旧完整备份先采用旧规则验证，不能直接用新摘要把有效旧备份判为损坏。重复内容能够复用，同名不同内容不得静默覆盖；偏好引用 MUST 按验证后的身份映射，不可用引用明确显示。恢复及索引重建 MUST 在后台进行并显示状态，取消、空间不足、校验错误或身份升级失败不得破坏已有可用词典。

#### Scenario: 恢复到已有词典的设备

- **WHEN** 设备已有相同真实文件组或同名但内容不同的词典
- **THEN** 相同内容复用已有身份，不同内容可区分并存
- **AND** 语言首选、候补及原选择映射到正确词典，不按名称猜测对应关系

#### Scenario: 恢复中断或校验失败

- **WHEN** 恢复被取消、空间不足、内容摘要不匹配或路径越界
- **THEN** 系统显示失败状态，未完成内容不进入可查询状态
- **AND** 已有词典及其偏好保持完整

#### Scenario: 恢复旧身份的完整备份

- **WHEN** 旧完整备份的摘要覆盖原父目录，实际完整文件仍可按旧规则校验
- **THEN** 系统先完成旧校验，再确定真实文件组并建立恢复身份映射
- **AND** 不因新文件组算法不同误判旧备份损坏，也不丢弃旧选择引用

#### Scenario: 旧仅清单身份无法可靠关联

- **WHEN** 旧普通备份只有覆盖兄弟文件的摘要，没有原文件，重新导入的单独文件组无法可靠对应
- **THEN** 原待导入记录和引用保留，系统明确提供重新关联处理
- **AND** 不按同名自动覆盖、删除记录或宣称已经自动恢复

### Requirement: 旧备份和在线规则必须保持兼容

系统 MUST 保留已有在线词典备份内容及恢复语义。没有本地词典清单的旧备份 MUST 继续原有恢复且不清空本地词库或新偏好；版本 1 清单 MUST 保留旧选择并兼容新语言设置，已有新设置不得被缺失字段重置。按书开关字段缺失 MUST 解释为关闭，不能因恢复旧书而自动开启。无法解析的新清单版本 MUST 提示限制，保持已有数据及独立可恢复内容。系统不承诺旧应用能够完整恢复新版本清单。

#### Scenario: 恢复旧版备份

- **WHEN** 用户恢复没有本地清单但包含在线规则的旧备份
- **THEN** 在线规则按既有行为恢复，本地词典和新查询设置不因清单缺失被删除

#### Scenario: 清单版本不受支持

- **WHEN** 备份清单版本超出当前支持范围
- **THEN** 系统提示该部分无法恢复，保留已有词典及可独立恢复的旧备份内容

#### Scenario: 版本一选择与缺失开关

- **WHEN** 恢复版本 1 清单和缺少即时开关的旧书籍设置
- **THEN** 有效旧选择保留并提供语言迁移或分类，不覆盖已有新首选与候补
- **AND** 对缺失开关的书籍不自动启用即时查词
