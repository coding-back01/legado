# 本地词典展示规范

## Purpose

为现有离线词典提供适合连续阅读的展示体验，明确即时面板、完整词条、来源选择与管理界面的视觉层级及操作边界。在保留全部查询、资源和持久化行为的前提下，使用户可以辨认词头与来源、阅读长释义并快速回到原文。

## Requirements

### Requirement: 即时查词必须呈现分层且有界的阅读面板

系统 MUST 分开呈现查询词或实际词头、匹配说明、正文和来源，不将所有信息压入单行；面板 MUST 位于选区空间较充足的一侧，保持选词和既有文字操作可用。面板 MUST 提供关闭、来源选择和全文入口，正文区域独立滚动。

#### Scenario: 阅读中长按与关闭

- **WHEN** 本书已开启即时查词，用户长按形成稳定单词选区
- **THEN** 出现紧凑面板，正文仍可见，关闭或返回不改变阅读位置，关闭后同一旧选区不重新弹出

#### Scenario: 长释义与受限空间

- **WHEN** 释义超过面板可用高度或设备横屏
- **THEN** 正文在有界区域内滚动，滚动不触发阅读翻页；空间不足时可以隐藏预览但仍保留全文和关闭入口

### Requirement: 词条展示必须区分内容层级且不捏造字段

系统 MUST 将词头作为主标题，可靠音标与词性作为辅助信息，定义作为正文，例句以独立段落区分。缺失字段 MUST 不产生占位伪信息；匹配来源 MUST 保持可见可追溯。复杂词条 MUST 保留原文预览和完整排版入口。

#### Scenario: 字段与多候选

- **WHEN** 结果包含可靠音标、词性、例句或多个候选
- **THEN** 对应内容以不同文字层级显示，各候选可区分；只有实际存在的字段显示

#### Scenario: 完整词条与内部导航

- **WHEN** 用户展开全文或打开词条内部链接
- **THEN** 可以滚动完整正文、访问已有本地图片和音频并返回上一词条，词库脚本及自动网络加载继续被禁止

### Requirement: 来源与低频动作必须可发现且保持语义

系统 MUST 以词典名称提供切换入口，选择列表标识当前来源。查询语言、设置首选、词典管理 MUST 可通过最多一层操作菜单到达；查看其他词典 MUST 不自动改变首选或候补。

#### Scenario: 切换来源

- **WHEN** 用户点击来源并选择另一词典
- **THEN** 新结果标明来源，旧请求不能覆盖新结果，原首选保持不变；原有在线规则仍仅由用户主动选择使用

#### Scenario: 加载与错误

- **WHEN** 查询正在加载、未收录、来源不可用或处理失败
- **THEN** 状态文字清楚，保留切换、管理及关闭入口，不遗留上一结果的词头或匹配提示

### Requirement: 管理界面必须优先呈现可用性和查询角色

系统 MUST 显示每本词典名称、查询语言、首选或候补角色及不可用状态，并提供可见的文件导入入口。技术资料和原有排序、关联、重建、删除操作 MUST 保留。

#### Scenario: 管理已有或空词库

- **WHEN** 用户进入管理页
- **THEN** 空列表说明需自备词库并可直接导入；已有词库可辨认查询角色，仍可查看完整元数据和执行全部原操作

### Requirement: 展示必须适配主题与 Android 操作

系统 MUST 支持浅色、深色、阅读背景、系统字号、窄屏、横屏及宽屏；主要触控区域至少 48dp，图标具有可读标签，宽屏面板限宽。尺寸计算 MUST 使用实际窗口可用空间，不能因固定正文高度使主要操作越出窗口。

#### Scenario: 主题和字号变化

- **WHEN** 使用深色或阅读背景，或放大字体与旋转屏幕
- **THEN** 词头、正文及操作仍可辨认，正文可滚动，来源和关闭/全文入口可达，完整词条可使用系统返回关闭

#### Scenario: 功能兼容

- **WHEN** 用户查词形、切换候补、导入或管理词库，再回到阅读
- **THEN** 结果、语言首选、书籍开关、数据和既有在线入口保持原语义，不改变数据库及公共导入协议
