# 本地词典查询规范

## Purpose

本能力在阅读现有选词流程中提供手动触发的本地词典查询，以可切换的释义卡片呈现完整词条和本地资源，并记住用户上次选择，在保持阅读操作与在线规则兼容的前提下提供可预测的离线查词体验。

## Requirements

### Requirement: 本地查词必须由现有词典动作触发

系统 MUST 保持既有长按、分词、选区调整和选词菜单行为，仅在用户点击“词典”后查询选中文字。系统 MUST 不因选区建立或变化自动弹出释义，也不能为查词改变阅读页选中的原始文字。

#### Scenario: 用户选择及调整文字

- **WHEN** 用户长按、拖动选区、复制或执行其他既有选词操作
- **THEN** 选区与操作效果保持既有行为，不自动开始本地查询

#### Scenario: 用户主动查询

- **WHEN** 用户选好文字并点击“词典”
- **THEN** 系统以该文字开始查询并显示释义卡片
- **AND** 关闭卡片后仍在原阅读位置

### Requirement: 系统必须全局记住上次本地词典

系统 MUST 使用用户上次选择的本地词典，跨书籍和应用重启保留该选择，不按书籍或推测的文字语言自动切换。用户手动切换后 MUST 立即用新词典查询当前文字并记住选择，即使该词典未命中也不回退到其他词典。

#### Scenario: 跨书籍和重启继续查词

- **WHEN** 用户选择词典甲后更换书籍或重启应用，再点击“词典”
- **THEN** 系统继续使用词典甲

#### Scenario: 手动切换但没有结果

- **WHEN** 用户在卡片内切换到词典乙，而乙没有收录查询词
- **THEN** 卡片显示乙未收录，下一次仍默认使用乙

#### Scenario: 首次使用及历史选择失效

- **WHEN** 没有有效的上次选择
- **THEN** 首次只有一本可用词典时直接使用该词典，首次有多本时显示选择入口，没有本地词典时显示导入入口
- **AND** 曾选择的词典已被删除或不可用时说明原因并让用户重新选择

### Requirement: 查询必须离线并隔离并发结果

系统 MUST 在后台查询本地词库，禁止因本地未命中而自动调用在线规则或加载远程资源。词典切换、卡片关闭和新请求 MUST 阻止旧请求更新当前卡片。系统 MUST 避免每次查词重新遍历或载入整本词典，长释义不能阻塞阅读操作。

#### Scenario: 断网或未收录

- **WHEN** 设备断网或当前词典没有查询结果
- **THEN** 已收录词仍能显示释义及已有本地资源，未收录词显示明确状态和切换入口
- **AND** 本地查词不产生自动网络请求

#### Scenario: 快速切换词典

- **WHEN** 用户在词典甲尚未返回时切换到词典乙
- **THEN** 甲的迟到结果不能覆盖乙的查询状态或结果

#### Scenario: 大型词库重复查询

- **WHEN** 用户在已完成导入的大型词库中连续查询多个词
- **THEN** 系统按索引读取相关词条，不为每次查询重新遍历整个词库
- **AND** 用户能够关闭卡片或切换词典

### Requirement: 语言候选必须保持原词优先且可追溯

系统 MUST 优先使用原文精确匹配，其次使用词典自身的别名和词形映射，再尝试受限的英文词形还原、中文繁简及必要规范化候选。原始正文和词头 MUST 保留，多个候选不能被不可逆地合并，结果 MUST 展示实际命中的词头。古汉语通假关系仅采用词库明确声明的映射；日韩语首版支持原文及词库映射，不要求额外活用还原。

#### Scenario: 原词和转换候选同时存在

- **WHEN** 查询文字与转换后的候选在词典中分别有词条
- **THEN** 原词精确结果优先，系统不会以转换结果替换原词结果

#### Scenario: 英文不规则词形

- **WHEN** 查询 `went` 且词典映射或已验证的离线词形候选指向存在的 `go` 词条
- **THEN** 系统返回对应词条并显示实际词头 `go`
- **AND** 不能用简单删后缀或不受限模糊匹配产生无依据的结果

#### Scenario: 繁简及古汉语多义

- **WHEN** 原文没有精确结果且繁简转换得到多个可能词头
- **THEN** 系统保留可区分的候选及原始释义，不把不同词条合成一个释义
- **AND** 未由词库声明的通假关系不会被自动推断为命中

#### Scenario: 多义项及日韩语

- **WHEN** 一个词头有多个义项，或用户查询日语、韩语的原词及词库已有别名
- **THEN** 系统保留对应词条和义项，不套用英文专用规则修改查询文本

### Requirement: 释义卡片必须完整展示词条及本地资源

系统 MUST 显示查询文字、当前词典和实际词头，支持释义滚动及展开、基础排版、音标、表格、图片、内部词条跳转和手动播放本地音频。词条 MUST 不被无提示截断，也不能串入下一词条；展示 MUST 适配应用主题、字号和生命周期。

#### Scenario: 长词条及富文本

- **WHEN** 词条包含超过卡片高度的释义、表格、音标或本地图片
- **THEN** 用户能够滚动或展开查看完整内容，字符与资源按支持能力显示
- **AND** 不显示相邻词条的正文

#### Scenario: 内部链接与音频

- **WHEN** 用户点击有效的词条内部链接或本地发音入口
- **THEN** 系统打开目标词条且允许返回，或按用户操作播放本地音频
- **AND** 切换词典或关闭卡片时停止当前音频

#### Scenario: 缺失资源及循环跳转

- **WHEN** 词条资源缺失、链接目标不存在或出现循环跳转
- **THEN** 系统说明对应问题并保留可显示的正文，不无限加载或崩溃

### Requirement: 词库展示必须受本地内容边界约束

系统 MUST 禁止词库脚本执行、自动网络资源和未经授权的本地文件读取。词库内部导航 MUST 限定在受控词条和资源范围；外部链接只有用户明确选择后才能交给外部浏览器。不支持的交互排版 MUST 提示限制，不能无提示隐藏必要释义。

#### Scenario: 词条包含主动内容

- **WHEN** 词条包含脚本、远程图片、自动跳转或越界资源引用
- **THEN** 这些内容不会执行或自动加载，安全可读的释义继续显示

#### Scenario: 用户选择外部链接

- **WHEN** 用户明确请求打开词条中的外部网页链接
- **THEN** 系统通过外部浏览器处理，词典展示环境不获得通用网页导航权限

### Requirement: 现有在线词典和导入行为必须保持兼容

系统 MUST 保留现有在线词典规则、规则 JSON 和 `/dictRule` 导入路径。用户 MUST 能主动使用已有在线来源；进入在线来源不得清除上次本地词典选择。本地词库不能覆盖或被当成在线规则导入。

#### Scenario: 已有在线词典用户升级

- **WHEN** 用户尚未导入本地词典并继续使用已有在线词典及规则导入
- **THEN** 原有功能仍可用，界面同时提供明确的本地词典导入入口

#### Scenario: 本地与在线来源切换

- **WHEN** 用户显式使用在线来源后再次进入本地查词
- **THEN** 上次本地选择仍可恢复，在线规则数据没有被本地导入修改
