## RENAMED Requirements

- FROM: `### Requirement: 本地查词必须由现有词典动作触发`
- TO: `### Requirement: 本地查词必须兼容手动动作与按书即时模式`
- FROM: `### Requirement: 系统必须全局记住上次本地词典`
- TO: `### Requirement: 系统必须按语言保存首选本地词典`

## MODIFIED Requirements

### Requirement: 本地查词必须兼容手动动作与按书即时模式

系统 MUST 保留既有长按、词边界、选区调整和选词菜单，并提供按书开启、跨重启保留的即时查词模式。旧书、新书和旧设置缺少该开关时 MUST 默认关闭；关闭时仅点击“词典”触发查询。开启时，初次长按形成稳定单词选区 MUST 能查看即时释义并继续使用复制、标注和选区调整。系统 MUST 不改写原选中文字，不因拖动、复制、翻页或关闭而连续触发自动查询，不改变阅读位置。

#### Scenario: 用户选择及调整文字

- **WHEN** 当前书即时模式关闭，用户长按、拖动选区、复制或执行其他既有选词操作
- **THEN** 选区与操作效果保持既有行为，不自动开始本地查询

#### Scenario: 用户主动查询

- **WHEN** 用户选好文字并点击“词典”
- **THEN** 系统以该文字开始查询并显示释义卡片
- **AND** 无论即时模式是否开启，关闭卡片后仍在原阅读位置

#### Scenario: 按书启用并记忆即时模式

- **WHEN** 用户只在书甲启用即时模式，长按形成稳定单词选区，再换书或重启
- **THEN** 书甲能够显示即时释义且继续保留文本操作入口，重启后开关仍开启
- **AND** 没有启用的书乙和旧设置仍按原菜单查询，不自动开启

#### Scenario: 拖动与关闭不重复弹出

- **WHEN** 用户在即时查询中拖动选区、关闭卡片、翻页或换书
- **THEN** 原请求与旧结果失效，拖动期间不连续查询
- **AND** 多词或多行选区仍可通过菜单主动查询，关闭后不会因同一旧选区重新弹出

### Requirement: 系统必须按语言保存首选本地词典

系统 MUST 按明确的查询语言保存用户设置的首选本地词典及有序候补，跨书籍和重启保持。中文和英文首选 MUST 相互独立；语言不明时 MUST 允许明确选择，不能仅因应用语言、拉丁文字或汉字而静默认定。首选失效 MUST 说明原因并让用户处理，不能把失效当作未收录。显式设置首选后 MUST 立即用于当前查询，即使未收录也保留该设置；候补命中或主动查看其他结果不得改写首选。升级 MUST 保留旧的全局选择作为迁移输入，且不覆盖已有新设置。

#### Scenario: 跨书籍和重启继续查词

- **WHEN** 用户分别设置中文词典甲和英文词典乙后换书或重启，再执行明确语言的查询
- **THEN** 中文查询继续从甲开始，英文查询继续从乙开始，两组设置不相互覆盖

#### Scenario: 手动切换但没有结果

- **WHEN** 用户明确将词典丙设为当前语言首选，而丙没有收录查询词
- **THEN** 首选仍为丙，系统按已配置候补规则处理未收录状态
- **AND** 下一次查询仍从丙开始，不能把候补结果当成新的首选

#### Scenario: 首次使用及历史选择失效

- **WHEN** 没有有效首选，或此前首选被删除、缺少文件或不可用
- **THEN** 系统显示相应选择或导入入口；明确语言下首次只有一本已分类可用词典时能够直接使用，有多本时由用户选择
- **AND** 历史失效说明原因，不静默替换为另一词典或自动调用在线规则

#### Scenario: 查询语言不明确

- **WHEN** 输入语言无法可靠确定，或词典缺少可用语言信息
- **THEN** 系统提供明确语言或词典选择入口，未确认前不套用英文候选或错误语言的自动候补
- **AND** 用户明确指定的语言优先于不准确的词库元数据

#### Scenario: 升级保留旧选择

- **WHEN** 用户升级后只有旧全局词典选择，或迁移再次执行
- **THEN** 有效且语言明确的旧选择能初始化对应首选；语言不明时保留选择并提供分类入口
- **AND** 旧词库、排序及用户已设置的新首选和候补不被清空或重复覆盖

### Requirement: 查询必须离线并隔离并发结果

系统 MUST 在后台查询本地词库并处理释义，禁止因本地未命中而自动调用在线规则或加载远程资源。词典切换、选区变化、换书、翻页、卡片关闭和新请求 MUST 阻止旧查询、摘要及资源结果更新当前卡片。系统 MUST 避免每次查词重新遍历或载入整本词典，长正文读取和预处理不能阻塞关闭、切换和其他阅读操作。

#### Scenario: 断网或未收录

- **WHEN** 设备断网或首选词典没有查询结果
- **THEN** 已收录词仍能显示释义及已有本地资源，未收录词按用户配置的本地候补查询或显示明确状态和切换入口
- **AND** 本地查词不产生自动网络请求

#### Scenario: 快速切换词典

- **WHEN** 用户在词典甲尚未返回时切换到词典乙
- **THEN** 甲的迟到结果不能覆盖乙的查询状态、摘要或全文

#### Scenario: 大型词库重复查询

- **WHEN** 用户在已完成导入的大型词库中连续查询多个词
- **THEN** 系统按索引读取相关词条，不为每次查询重新遍历整个词库
- **AND** 用户能够关闭卡片或切换词典，原文预处理不得阻塞这些操作

#### Scenario: 旧选区或视图失效

- **WHEN** 查询期间用户改变选区、翻页、换书、关闭卡片或销毁原视图
- **THEN** 旧请求不再向当前阅读页提交摘要、全文或资源结果
- **AND** 取消不改变已保存的首选、候补或书籍开关

### Requirement: 语言候选必须保持原词优先且可追溯

系统 MUST 优先使用原文精确匹配，其次使用词典自身的别名和词形映射，再尝试必要规范化及适用语言的有限候选。额外英文词形候选 MUST 只用于明确英文查询，不能因输入使用拉丁字母而套用于其他或未确定语言。原始正文和词头 MUST 保留，多个真实候选不能被不可逆合并或仅因第一项命中而隐藏；结果 MUST 展示实际词头及适用的匹配来源。古汉语通假关系仅采用词库明确映射；日韩语保留原文及词库映射，不增加活用还原承诺。

#### Scenario: 原词和转换候选同时存在

- **WHEN** 查询文字与转换后的候选在词典中分别有词条
- **THEN** 原词精确结果优先，系统不会以转换结果替换原词结果

#### Scenario: 英文不规则词形

- **WHEN** 明确英文查询 `went` 且词典映射或已验证的离线词形候选指向存在的 `go` 词条
- **THEN** 系统返回对应词条并显示实际词头 `go`
- **AND** 不能用简单删后缀或不受限模糊匹配产生无依据的结果

#### Scenario: 繁简及古汉语多义

- **WHEN** 原文没有精确结果且繁简转换得到多个可能词头
- **THEN** 系统保留可区分的候选及原始释义，不把不同词条合成一个释义
- **AND** 未由词库声明的通假关系不会被自动推断为命中

#### Scenario: 多义项及日韩语

- **WHEN** 一个词头有多个义项，或用户查询日语、韩语原词及词库已有别名
- **THEN** 系统保留对应词条和义项，不套用英文专用规则修改查询文本

#### Scenario: 防止英文近似词误命中

- **WHEN** 词库没有原词或显式词形映射，英文查询 `singing`，且词库同时收录 `sing` 和 `singe`
- **THEN** 有效还原指向 `sing`，不能将 `singe` 当作 `singing` 的正确词形
- **AND** `wolves`、`knives` 等验收样本使用有依据的词形关系，不以不存在的删后缀结果代替

#### Scenario: 保留真实词形歧义

- **WHEN** 原词和词库映射均未命中，英文查询 `leaves` 的有限候选存在 `leaf` 与 `leave` 两个有效词头
- **THEN** 系统保留可区分的候选及对应释义，不因第一项命中而隐藏另一项
- **AND** 词典自己的精确结果或显式映射仍优先于额外候选

### Requirement: 释义卡片必须完整展示词条及本地资源

系统 MUST 显示查询文字、实际词头和当前结果来源，支持短释义到完整词条的展开或降级展示。全文 MUST 保留滚动、基础排版、音标、表格、图片、内部词条跳转和手动播放本地音频，不能因摘要无提示丢失正文或串入下一词条。展示 MUST 适配应用主题、字号、生命周期和阅读操作；不得追加与词库正文重复的无必要词头标题。

#### Scenario: 长词条及富文本

- **WHEN** 词条包含超过卡片高度的释义、表格、音标或本地图片
- **THEN** 用户能够滚动或展开查看完整内容，字符与资源按支持能力显示
- **AND** 摘要不会替代全文，也不显示相邻词条的正文

#### Scenario: 内部链接与音频

- **WHEN** 用户点击有效词条内部链接或本地发音入口
- **THEN** 系统打开目标词条且允许返回，或按用户操作播放本地音频
- **AND** 切换词典或关闭卡片时停止当前音频

#### Scenario: 缺失资源及循环跳转

- **WHEN** 词条资源缺失、链接目标不存在或出现循环跳转
- **THEN** 系统说明问题并保留可显示正文，不无限加载或崩溃

#### Scenario: 即时卡片保留阅读操作

- **WHEN** 即时卡片出现在阅读页，或用户处于小屏、横屏和放大字号环境
- **THEN** 当前选词和文本操作入口可继续使用，阅读位置与分页不改变
- **AND** 空间不足时提供可收起入口和完整查看能力，不遮住选词而无法操作

### Requirement: 现有在线词典和导入行为必须保持兼容

系统 MUST 保留现有在线词典规则、规则 JSON 和 `/dictRule` 导入路径。用户 MUST 能通过明确主动入口使用在线查询或已有翻译规则；进入在线来源不得清除语言首选、本地候补和按书开关。本地词库不能覆盖或被当作在线规则导入，本地未命中、卡片展开或词形候选不得触发自动在线查询。

#### Scenario: 已有在线词典用户升级

- **WHEN** 用户尚未导入本地词典并继续使用已有在线词典及规则导入
- **THEN** 原有功能仍可用，界面提供明确本地导入入口

#### Scenario: 本地与在线来源切换

- **WHEN** 用户显式使用在线来源后再次进入本地查词
- **THEN** 已保存的语言首选、本地候补和按书开关保持，在线规则数据没有被本地导入修改

## ADDED Requirements

### Requirement: 本地候补查询必须有序且不改写首选

系统 MUST 仅在首选明确未收录时按用户配置顺序查询同语言本地候补，首个命中后停止自动查询并标明来源。未配置词典、在线来源及重复来源 MUST 不进入自动候补；词典不可用或读取错误不得伪装成未收录。主动查看其他词典 MUST 与设置首选区分，不能自动改变持久化偏好。

#### Scenario: 候补命中后继续使用原首选

- **WHEN** 首选甲未收录，候补乙命中，候补丙仍排在乙之后
- **THEN** 显示乙及实际词头，不自动查询丙，也不把乙保存为首选
- **AND** 下一次查询仍从甲开始

#### Scenario: 所有候补未命中

- **WHEN** 首选及全部配置候补均未收录
- **THEN** 显示明确未收录状态并允许主动选择其他来源
- **AND** 不查询未配置词典或自动联网

#### Scenario: 首选错误与主动查看其他词典

- **WHEN** 首选读取失败，或用户主动展开其他本地词典结果
- **THEN** 读取错误可见，主动结果标明来源
- **AND** 两者都不静默修改首选或候补顺序

### Requirement: 短释义必须可靠并保留全文入口

系统 MUST 优先显示可可靠取得的短释义，并保留查询词、实际词头、来源和全文入口。音标、词性及例句仅在词库提供且能够可靠识别时显示；抽取不可靠时 MUST 展示可读原词条，不能把任意截取、词头、版权段落或生成内容当作释义。可靠摘要省略内容 MUST 可见地说明，并能够展开完整词条。摘要与全文 MUST 遵守既有本地资源和脚本边界。

#### Scenario: 可靠短释义与全文

- **WHEN** 词库提供可以可靠识别的定义及可选音标或词性
- **THEN** 首屏呈现可读短释义与已有字段，用户能够展开全文及本地资源
- **AND** 原始词条不被摘要替换或改写

#### Scenario: 摘要不可靠或字段缺失

- **WHEN** 正文为复杂自由排版、缺少定义边界，或没有音标及词性
- **THEN** 系统降级为可读原词条并保留全文入口，不伪造缺失字段
- **AND** 不能将版权、词头或正文前若干字符无依据标为短释义

#### Scenario: 摘要省略与候选分离

- **WHEN** 可靠定义超过首屏范围，或查询存在多个真实候选词头
- **THEN** 省略和全文入口可见，候选分别标明词头及来源
- **AND** 不将不同词头或义项不可逆地合并成一条释义
