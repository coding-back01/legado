## 变更动机

阅读目前的词典功能主要依靠在线查询规则，无法直接导入用户已有的离线词库。增加接近 Kindle 的本地查词体验，让用户沿用现有选词操作，在阅读页点击“词典”后离线查看释义，并方便地切换已导入的词典。

## 变更内容

- 新增本地词典管理与导入，首版覆盖 MDict、StarDict、Kindle MOBI/PRC、DSL、DICTD、XDXF、BGL 七类格式；按实际文件结构识别，逐类建立兼容样本与支持边界。
- 支持词典文件、配套文件集、目录，以及 ZIP、普通单卷 RAR、7z、tar.gz 导入；关联样式、图片、音频，导入时建立离线查询索引。
- 保持现有分词、长按、选区调整和选词菜单行为。只有用户点击“词典”才开始查询，不自动弹出释义。
- 使用全局记忆的上次所选词典，跨书籍和应用重启保留；弹窗内可以切换并重新查询当前选中文字，不按语言自动更换词典。
- 中英文重点验收，兼顾古汉语及日韩语。原文匹配优先，支持词库别名、词形、英文词形还原和中文繁简候选；不改写选中文字或原始释义。
- 支持可滚动与展开的长释义、基础样式、音标、表格、图片、内部词条跳转和手动播放本地音频。词库脚本不执行，远程资源不自动加载。
- 普通备份保存词典清单、设置与当前选择；完整备份可选择包含词典原文件和资源，查询索引恢复时重建。

### 范围与非目标

本次仅实现 Android 阅读页的本地词典及其管理、持久化和备份能力。应用不提供词库；不增加生词本、背词、整句翻译、自动识别书籍语言、自动选词、后台联合查询或词典商店。不解密受 DRM 保护的词库，不承诺复刻全部词库脚本交互；分卷和带密码的压缩包提示用户先解压。EPWING、Slob、ZIM 等留待后续独立评估。

### 可观察的验收条件

1. 七类格式分别具备可重复的导入及查词证据，支持的版本、编码、压缩和资源变体有明确清单；损坏、缺文件或不支持的变体不会被标记为成功。
2. 断网后仍能查询已导入的词典并查看其本地资源；复制、调整选区和其他既有阅读操作不会触发查询。
3. 手动切换词典后，当前查询立即使用新选择；更换书籍及重启应用仍记住该选择，旧请求不会覆盖新结果。
4. 词形和繁简候选返回正确词条并标明实际词头，长释义不会截断或串入下一词条，词条跳转可以返回。
5. 导入可取消，失败不留下可查询的半成品；移动导入来源不影响已导入词典，删除只清理应用管理的副本及索引。
6. 普通及完整备份按所选范围恢复；缺失文件明确显示待导入，旧版备份和在线词典规则仍可使用。

## 能力清单

### 新增能力

- `local-dictionary-import`：多格式词典及资源导入、校验、索引建立、管理与兼容范围。
- `local-dictionary-lookup`：阅读页手动查词、上次词典记忆、语言候选、离线富文本展示及既有行为兼容。
- `local-dictionary-backup`：词典清单、偏好、可选原文件备份与可恢复索引。

### 修改能力

无。已有规范没有本地词典能力；本变更不改变现有规范中的维护、发布和兼容要求。

## 影响

- `app/`：阅读页、词典界面、文件导入、MOBI 基础代码、查询服务、存储、备份恢复、字符串与帮助文档，以及相应测试。
- `app/schemas/`：新增词典目录元数据需要 Room 迁移、结构导出和迁移测试。大词库的索引独立保存，不写入主数据库。
- `gradle/libs.versions.toml` 与 Android 构建：可能新增格式解析和语言候选依赖；必须先核对许可证、原生构建、最低 API 21 与资源成本，不升级已有固定依赖。
- `.github/dependabot.yml`：为新增的兼容性固定 LZO 依赖忽略普通版本更新，保留独立安全更新渠道。
- `modules/book/`、`modules/rhino/`、`modules/web/`：本方案不要求修改，不引入网页端词典功能。
- 兼容性：保留现有在线 `DictRule` JSON、`/dictRule` 导入路径和备份恢复语义；本地文件使用独立数据模型与入口。混合展示时本地查询不自动调用在线规则。
- 风险：大文件解析与解压可能耗尽内存或空间；HTML、资源路径和压缩包必须受本地资源边界约束；多格式转换可能丢失别名、词形或词条边界。通过后台导入、限额与边界检查、原子发布、独立索引和逐格式样本验证控制风险。
- 调研证据只用于确定需求和测试方向，尚不代表实际文件已兼容；解析库选型与性能基线属于实施前段的技术验证任务。
