# 本地词典实施验证记录

本记录对应 `add-local-dictionaries`，实现与首次验证覆盖 2026-10-08 至 2026-10-09；最终完整复测于 2026-10-11 执行。只登记实际结果；规划和来源调研不作为兼容证据。

## 构建与静态检查

- 使用 JDK 17、Android SDK 36、NDK 27.2.12479018、CMake 3.22.1，以两个 Gradle worker、4 GiB 堆和 1 GiB metaspace 执行离线构建。
- 完整 `:app:testAppDebugUnitTest` 成功：191 项中 190 项执行通过，1 项为仓库原有的外部 Latest JSON 资产烟测忽略项。本功能的解析、展示、摘要、缓存与长度边界 29 项全部通过。
- `:app:lintAppDebug` 与 `:app:assembleAppDebug` 成功，最终 lint XML 为零 issue；测试 APK 也构建成功。
- APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 四种词典共享库，`llvm-readelf` 核对 LOAD 段均为 `0x4000` 对齐。运行设备均为 arm64-v8a，不将其他架构的构建视为运行验证。
- Room 75→76 自动迁移、导出结构 `76.json` 及保留旧在线规则的迁移测试通过。
- 新增运行时依赖仅为固定 LZO 与 libmobi；未升级已有固定依赖、签名或 CI。MDict 摘要使用独立 RIPEMD-128，七个公开向量通过，不改变 Hutool 的加密提供者环境。
