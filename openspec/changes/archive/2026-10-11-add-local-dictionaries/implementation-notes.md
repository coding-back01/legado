# 实施接续与交付记录

## 实现范围

七类本地词典已接入同一导入、独立索引和阅读卡片流程。保持现有选词操作，点击“词典”才查询；全局记忆上次本地词典。资源留在应用受控目录，脚本和自动网络关闭，保留在线规则显式使用。

备份包含版本清单，可选原文件与资源；恢复重建索引并映射身份。Room 为 75→76 增量迁移；大词库不进入主数据库。帮助与八种语言的字符串资源已加入。

## 重要决定与修复

- MOBI 使用固定 libmobi 0.12，读取前选择 MOBI 部分；UTF-16/ORDT 标签已经被上游转换为 UTF-8，与正文编码分别处理，保留词典输入/输出语言字段。
- MDict 使用独立 RIPEMD-128，不注册通用加密提供者；LZO 排除未使用的日志、注解依赖。
- 重建旧完整数据保留于按 ID 命名的恢复目录；失败回滚，启动清理中断暂存与孤儿，不破坏其他词典。
- 查询缓存包含键和正文的有界计费，不保留句柄；导航历史只存查询记录；候选溢出明确报错。
- 文件、文本行、XML、归档及内嵌资源均有上限；资源路径校验深度及目录边界。内嵌资源的新目录计入文件条目上限。
- API 21 的归档直接使用原生文件描述符，避免 Java ByteBuffer 回调差异；既有通用解压默认行为不变。
- 测试授权提供者及 Activity 用 Java/平台 API，在测试 APK 自身 UID 准备只读文件，根路径规范化。授权检查不等待没有显示窗口的 Activity 绘制。
- API 21 模拟器恢复物理显示设置，避免截屏与注入触点坐标错位；卡片测试不为检查正文而开启脚本。
- 本地音频读取在 IO，绑定视图生命周期；切换与关闭释放。展开状态随旋转保留，夜间和字号优先保证释义可读。

## 验证与工作区

实际结果见验证记录、兼容性矩阵与性能基线，最终以任务清单为准。Gradle 使用 JDK 17、两个 worker 与 1 GiB metaspace；离线设备任务缺 UTP 缓存时通过 adb 安装及 instrumentation 执行。

工作区修改均属于此变更；没有升级已有固定依赖、修改签名或 CI。没有创建提交、PR 或归档。后续如继续扩展兼容范围，应增加可分发样本及断言，并同步矩阵；不能只按词典名称宣称支持。
