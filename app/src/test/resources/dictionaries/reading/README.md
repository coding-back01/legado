# 阅读体验迭代夹具

本目录的清单与词条均为自建测试内容，沿用仓库 GPL-3.0 许可，不属于应用内置词库，不包含用户商业词库。清单中的零摘要用于解码场景，不表示可验证的真实文件内容；真实身份验证使用测试临时目录中的文件计算。

- `catalog-v1.json`：旧普通清单、旧选择与待导入记录。
- `catalog-v2.json`：新版普通清单、身份版本与明确语言首选示例。
- `definition.html`：带明确定义边界及可选字段的最小正文。
- `complex.html`：版权开头、自由布局和脚本依赖的原文降级场景。
- 词形、同目录多词库、共享资源及旧身份的最小内容由 `EnglishDictionaryFormsTest`、`DictionaryFileGroupTest` 和 `DictionaryQueryTest` 在测试中自建，内容及预期与断言一起维护。

已有七类格式的来源和许可继续见上一级说明。此处的版本二清单随生产协议和兼容测试核对，不作为协议已经实现的证据。
