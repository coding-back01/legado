# 本地 MOBI 词典解析依赖

本目录保留 libmobi 0.12 的解析源文件，来源为 [上游仓库](https://github.com/bfabiszewski/libmobi)，固定提交为 `85dcfe803fc2a21020ddcf15c3eb66b93d388add`（`v0.12`）。原文件版权说明保持原样，许可证为 LGPL-3.0 或后续版本，完整文本见 `COPYING`。

仅编译容器、解压、元数据、索引和正文资源解析，不编译加密、写回、命令行工具及外部 XML 生成器。上层通过窄接口导入词典，查询使用应用自有索引。构建使用 Android NDK 27.2.12479018，最低 API 21，链接系统 zlib；共享库采用 16 KiB 页对齐。

升级时需核对上游修复并重新执行无压缩、PalmDOC、HUFF/CDIC、词形索引、旧词形结构、受保护输入和损坏索引测试。来源及许可证信息应随应用分发保留，不能只复制编译产物。

本地兼容补丁：`util.h` 的正文上限允许由编译参数覆盖，本应用固定为 512 MiB；原文件上限仍为 256 MiB。词典桥接层支持标签 22 的别名关系以及附加的词典检索面板，不执行面板脚本，别名限制为 16 层。

首次引入时仅清理上游 C 源文件及头文件的行尾空白及多余文件末尾空行，以通过仓库提交空白门禁；不改变代码、版权说明或许可证内容。其余行为补丁见上文。
