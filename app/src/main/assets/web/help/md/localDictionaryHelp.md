# 本地词典

阅读不提供词库。请导入自己已有的词典文件，导入完成后可以断网查词。

## 导入

在词典管理中打开“本地词典”，选择“导入词典文件”或“导入词典目录”。多文件词典建议选择整个目录，或者同时选择主文件及配套文件。目录或压缩包中有多本词典时，可以勾选需要导入的词典。

| 格式 | 通常需要的文件 |
| --- | --- |
| MDict | MDX；有图片、声音或字体时还需配套 MDD，外置样式文件也要一起选择 |
| StarDict | IFO、IDX 或 IDX.GZ、DICT 或 DICT.DZ；可选 SYN 和资源目录或资源包 |
| Kindle 词典 | 含词典索引的 MOBI、PRC，或内部结构兼容的 AZW |
| DSL | DSL 或 DSL.DZ；图片、声音可由配套 FILES.ZIP 提供 |
| DICTD | INDEX 和 DICT 或 DICT.DZ |
| XDXF | XDXF 或 XDXF.DZ，以及相关资源 |
| Babylon | BGL，包含词条及内嵌资源 |

可以直接导入普通单卷 ZIP、RAR、7z 和 tar.gz。分卷或带密码的压缩包请先解压再导入。普通电子书即使名字是“词典”，没有词典索引时也不能用于划词查询。受 DRM 保护的词库以及未支持的版本会给出明确提示。

导入显示进度并可以取消，只有准备完成的词典才会显示为可用。原文件会复制到应用管理的目录，之后移动外部原文件不会影响查询。删除词典只移除应用内副本及查询索引，保留外部原文件。同名但内容不同的词典会区分显示，相同文件组重复导入不会重复存储。

## 阅读时查词

沿用现有长按和拖动操作选中文字，然后点击选词菜单里的“词典”。应用不会因为选区变化自动弹出释义。

每次打开使用上次选中的本地词典。点击卡片上的词典名称可以手动切换；跨书籍及重启应用仍会记住选择，不根据书籍语言自动更换。当前词典没有收录时，可以切换其他词典。在线来源需要主动选择，本地查词不会自动联网。

卡片显示选中文字和实际命中的词头。原词优先；词典自带别名、词形索引及额外的英文词形、中文繁简候选可以帮助找到对应词条。繁简候选保留各词条原始释义，不将不同字义合并；古汉语通假关系只采用词库提供的映射。日韩语支持原词和词库已有别名，不额外推断活用。

长释义可以滚动或展开，内部词条链接可以返回。图片和发音使用本地资源，声音点击后才播放，关闭卡片或切换词典会停止。部分互动排版可能以静态内容显示，词库脚本不执行，远程资源不自动加载。缺少可选资源时仍能查看已有文字。

## 管理与恢复

在列表中点击词典可以查看信息、调整顺序、删除副本或重建查询索引。索引损坏时可以重建；原词库受损则需要重新导入。

普通备份保存词典清单、顺序和选择，默认不带体积较大的原词库及资源。在备份设置中启用“备份包含本地词典文件”可创建完整备份。恢复时重建索引；只有清单而没有文件的词典显示“待重新导入”，补入对应文件后恢复可用。

## 格式及资源说明

兼容性以实际结构、版本、编码及压缩方式为准，同名词典的不同转制版本可能不同。处理过程中有文件数量、正文大小及资源限额，损坏、超限或存储不足会明确报错，不把半成品当成成功导入。应用不会解密账号绑定的词库。

MDict 已验证 1.x、2.x，Kindle 词典使用含词典索引的 MOBI 部分；MDict 3.x、纯 KF8 和 KFX 不在支持范围内。复杂互动样式会以静态内容显示，夜间模式和用户字号优先保证释义可读。一次查询最多处理 64 个候选或独立义项，超过上限会提示，避免无提示丢弃内容。

本地 MOBI 解析使用 LGPL-3.0 或后续版本的 libmobi 0.12，LZO 解压使用 GPL-3.0 的 lzo-core 1.0.6，完整来源和许可证在项目源码及应用许可证说明中保留。
