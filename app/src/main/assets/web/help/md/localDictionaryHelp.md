# 本地词典

阅读不提供词库。请导入自己已有的词典文件，导入完成后可以断网查词。

## 导入

在词典管理中打开“本地词典”，选择“导入词典文件”或“导入词典目录”。多文件词典建议选择整个目录，或者同时选择主文件及配套文件。目录或压缩包中有多本词典时，可以勾选需要导入的词典。

| 格式 | 通常需要的文件 |
| --- | --- |
| MDict | MDX；有图片、声音或字体时还需配套 MDD，外置样式文件也要一起选择 |
| StarDict | IFO、IDX 或 IDX.GZ、DICT 或 DICT.DZ；可选 SYN 和资源目录或资源包 |
| Kindle 词典 | 含词典索引的 MOBI、PRC，或内部结构兼容的 AZW |
| DSL | DSL 或 DSL.DZ；图片、声音可由配套 FILES.ZIP 提供 |
| DICTD | INDEX 和 DICT 或 DICT.DZ |
| XDXF | XDXF 或 XDXF.DZ，以及相关资源 |
| Babylon | BGL，包含词条及内嵌资源 |

可以直接导入普通单卷 ZIP、RAR、7z 和 tar.gz。分卷或带密码的压缩包请先解压再导入。普通电子书即使名字是“词典”，没有词典索引时也不能用于划词查询。受 DRM 保护的词库以及未支持的版本会给出明确提示。

导入显示进度并可以取消，只有准备完成的词典才会显示为可用。原文件会复制到应用管理的目录，之后移动外部原文件不会影响查询。删除词典只移除应用内副本及查询索引，保留外部原文件。同名但内容不同的词典会区分显示，相同文件组重复导入不会重复存储。

## 阅读时查词

首次默认沿用原有选词菜单：长按、拖动选区后点击“词典”。在阅读菜单中开启“本书即时查词”后，本书的稳定单词初选会显示阅读内轻卡片，复制、标注和选择符仍可使用。开关按书保存，其他书和旧设置不会自动开启；重启后保持。拖动、翻页、复制、关闭及换书会撤销旧卡片，不因同一选区自动重弹；多词选区仍可通过菜单主动查询。

在卡片中明确选择查询语言，本书的明确语言选择可保存。中文与英文分别配置首选和有序本地候补。词库缺少语言或声明不准确时，在管理页指定查询语言，原始元数据仍保留。应用不会只因文字使用拉丁字母或汉字而静默认定语言。

自动查询先用首选；仅在明确未收录时依次使用已配置的同语言候补，首个命中后停止并标明来源，不改写首选。损坏、缺文件、超限和读取错误直接提示，不当作未收录继续回退。点击词典名可以主动查看其他来源；只有“设为首选”才保存新首选。在线词典及已有翻译规则需要用户主动选择，本地未命中不自动联网。

可靠的明确定义先以原生短释义显示，音标、词性和例句只在词库实际提供时出现。省略内容会提示，随时可展开全文。自由排版、版权段、只有词头或依赖脚本的正文不会被截成伪释义，降级为可读原词条并保留完整查看。多个真实词头分别显示，原词和词库映射优先；额外英文还原只用于明确英文。通过词库映射、规范化、繁简或英文词形命中时，卡片显示实际词头和匹配方式。古汉语通假只采用词库映射，日韩语不额外推断活用。

全文可以滚动，内部词条链接可以返回。图片和发音使用当前词典的本地资源，声音只在点击后播放，关闭或切换停止。词库脚本不执行，远程资源不自动加载。小屏或横屏空间不足时，阅读卡片收起正文，仍可使用语言、完整查看及关闭入口，不改变正文分页。

## 管理与恢复

管理页提供语言指定、首选、有序候补加入或移除、候补上下移、原文件信息、排序、删除和索引重建。不同语言的首选相互独立，未分类词库仍可手动使用。重建保留用户语言，删除只清理应用副本，不删除外部原文件。

目录或归档中只勾选一本时，只发布其主文件、必要配套和明确关联资源。散落资源归属不明会要求选择关联，显式共享资源各自保留副本；不能默认复制整个父目录。旧副本中的多带文件不会自动清理。身份升级保留 ID、排序和可用索引，失败或取消保持旧可用数据。

新版备份清单为版本 2，保存身份版本、实际文件组、语言首选、候补和用户语言指定；按书开关跟随原书籍备份。普通备份不带正文、资源或索引，恢复后显示“待导入”；完整备份需显式开启“备份包含本地词典文件”，只打包实际组。旧版本 1 完整备份先按旧摘要校验，再归一化，不能被新规则误判损坏。资源归属暂不能明确的有效旧副本保留旧身份和可用内容，确认资源后升级。

旧仅清单如果摘要混入兄弟文件且原文件缺失，单独重新导入不能可靠自动匹配。记录及引用保留；导入实际词库后，在待导入条目选择“重新关联待导入词典”并确认来源，保留原名称、排序和查询引用，不按同名猜测。完整文件备份前，旧词典资源关系不明时需先确认关联。

恢复会校验路径、内容和身份，重复内容复用，同名不同内容不覆盖；取消、空间不足或校验失败回滚本次变化，原有词典和设置保持。同一清单重复恢复不覆盖用户后续改过的偏好。未知版本提示限制，没有词典清单的旧备份不清空现有词库；在线规则沿用原恢复语义。

## 格式及资源说明

兼容性以实际结构、版本、编码及压缩方式为准，同名词典的不同转制版本可能不同。处理过程中有文件数量、正文大小及资源限额，损坏、超限或存储不足会明确报错，不把半成品当成成功导入。应用不会解密账号绑定的词库。

MDict 已验证 1.x、2.x，Kindle 词典使用含词典索引的 MOBI 部分；MDict 3.x、纯 KF8 和 KFX 不在支持范围内。复杂互动样式会以静态内容显示，夜间模式和用户字号优先保证释义可读。一次查询最多处理 64 个候选或独立义项，超过上限会提示，避免无提示丢弃内容。

本地 MOBI 解析使用 LGPL-3.0 或后续版本的 libmobi 0.12，LZO 解压使用 GPL-3.0 的 lzo-core 1.0.6，完整来源和许可证在项目源码及应用许可证说明中保留。


## 阅读面板与完整词条

开启本书即时查词后，长按单词会显示阅读面板。词头、匹配来源与释义分区展示，较长预览可在面板内滚动。点击底部词典名称可以选择来源，点击“完整词条”查看原词条排版和资源；空间不足时保留这些入口。关闭按钮或返回键可收起面板，不改变阅读位置。

详情顶部的词典名称用于切换来源，右侧词典选项菜单保留查询语言、设为首选和管理入口。手动查看其他词典不会改变首选。管理列表显示查询语言与首选、候补角色，格式及完整元数据仍可在词典详情中查看。
