第一章 离线发布烟测
LEGADO_RELEASE_SMOKE_SENTINEL_20260830

这是只用于可丢弃 Debug 模拟器的离线文本夹具。它不访问网络，不读取用户文件，也不包含真实书籍、书源、账号、地址或备份数据。

第 01 段：清晨的窗边只有测试设备发出的微光。页面中的每个字符都来自仓库内夹具，用来确认本地导入、正文排版和翻页进度可以在完全离线的环境中重复执行。
第 02 段：这段文字故意保持普通标点和稳定长度。自动化只检查唯一标记和分页结果，不依赖字体渲染截图，也不会把模拟器证据扩大为其他设备的兼容承诺。
第 03 段：测试书籍进入的是 Debug 应用自己的数据库。执行完毕后测试会删除书籍记录和临时文件，正式包及用户数据空间不会参与这个过程。
第 04 段：阅读页采用自绘正文，截图不能单独证明内容正确。因此测试从排版模型读取完整正文，确认唯一标记存在，再调用真实翻页逻辑观察阅读位置增加。
第 05 段：如果目录加载、正文解析、页面布局或进度保存任一环节失败，烟测必须失败。外部网络是否可用不会改变这条结论，因为夹具没有任何远程依赖。
第 06 段：同一段流程会在最低 API 和目标 API 模拟器上分别执行。某个系统镜像不可用时只能记录未运行，不能把另一个模拟器结果冒充为缺失环境的通过证据。
第 07 段：这里继续提供足够多的可见文本，使常见手机分辨率和默认字号下都至少生成两个正文页面。测试不会通过缩小字号等方式制造偶然分页。
第 08 段：返回书架后，自动化会再次读取数据库，确认测试书仍存在且翻页位置已经持久化。随后才清理夹具，避免下一次运行受到旧进度影响。
第 09 段：这一流程只属于发布前 Debug 预检，不会进入正式签名工作流，也不会读取任何发布 Secrets。候选 APK 的签名与完整性在后续独立门禁中验证。
第 10 段：为了让测试结果可审计，运行脚本使用精确 annotation 过滤器。联网测试、迁移测试、性能测试以及可能污染数据的整个 instrumentation 套件都不会被默认执行。
第 11 段：设备或模拟器上的原始截图和日志只保存在忽略目录。版本化证据仅记录命令、镜像、包身份、通过或失败状态以及必要的脱敏摘要。
第 12 段：测试路径到这里仍然没有触发任何在线请求。正文的每一行都可以从版本化夹具复现，唯一标记也不会与真实用户内容发生混淆。
第 13 段：页面向后翻动时，阅读位置应严格大于初始位置。若正文意外只生成一个页面，测试不会跳过断言，而是明确报告夹具没有满足跨页要求。
第 14 段：书架断言与正文断言相互独立。前者证明导入记录仍存在，后者证明阅读模型真正取得了夹具内容，避免用单一数据库写入冒充完整阅读路径。
第 15 段：后续 API 36 预检还会覆盖输入法、导航、语言、RTL 和动态资源相关页面；这些页面检查不会替代本地文本的核心导入与翻页验证。
第 16 段：后续 API 21 预检用于覆盖最低系统边界。测试代码不调用高版本专属接口，也不增加 UIAutomator 依赖，优先使用现有 AndroidX Test、Espresso 和应用公开模型。
第 17 段：如果测试发现崩溃、正文错误、无法翻页或数据断言失败，正式发布继续冻结。只有真实运行成功的步骤才能在证据中标为通过。
第 18 段：假书源预览使用另一份内联离线数据，只打开预览并点击取消。前后书源数量必须一致，测试不会点击确认导入，也不会删除任何既有书源。
第 19 段：真机阶段不会运行本测试，因为它会写入 Debug 数据库。指定真机只允许同签名升级、启动和公开接口可读的非破坏性核对。
第 20 段：候选公开前仍要核对远端资产大小、摘要、ZIP 完整性、包名、版本、最低和目标 API、证书，以及 workflow、tag、Release target 的提交一致性。
第 21 段：这一段继续增加稳定文本长度，使横屏、竖屏以及不同系统栏高度下都保有跨页空间。自动化不假设固定页数，只要求页数大于一。
第 22 段：测试不使用 OCR 作为正文真实性的唯一证据。自绘页面的截图可用于人工定位，但最终断言来自排版后 TextChapter 的文本和页列表。
第 23 段：所有内容均为测试说明，没有作品正文或个人数据。夹具可随代码审查、回滚和重复构建，不需要外部下载或额外授权。
第 24 段：当本段排版完成后，夹具已经提供足够的跨页文本。发布烟测将保存真实结果，并继续执行下一阶段，而不会把未运行项目描述为成功。
